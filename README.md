# Keyflow

> Find your flow. One keystroke at a time.

A gamified typing app people come back to: timed tests, storybook typing, touch-typing lessons with a finger guide, daily challenges, streaks, XP, badges and a results screen worth screenshotting. Built from `Keyflow-Master-Spec.md`.

It is a static single-page app. No backend, no account, no tracking — progress lives in the browser's `localStorage`, and you can export/import it as JSON.

## Run it

```bash
npm install
npm run dev        # http://localhost:5173
npm test           # engine, streaks, XP, store, content, theme-contrast tests
npm run build      # production build in dist/
npm run preview    # serve dist/ locally (http://localhost:4173)
```

## Deploy it

`npm run build` produces a fully static `dist/` folder. Upload it to any static host — Netlify, Vercel, Cloudflare Pages, GitHub Pages, S3, or your own nginx. No server config or rewrite rules are needed: the app uses hash routing and relative asset paths, so it also works from a sub-folder.

It is an installable PWA (offline after first load). Icons are generated by `scripts/make-icons.mjs`.

## What's in it

| Area | What you get |
|---|---|
| **Typing engine** (`src/lib/engine.ts`) | Pure, tested. Per-character states, backspace / Ctrl+Backspace, raw + net WPM, accuracy, consistency, per-second series, per-key errors and speed, combo, code auto-indent. Timer starts on the first keystroke. |
| **Practice** | Time (15/30/60/120s), words (10–100), quotes, Zen, custom text, code (JS/Python/CSS/SQL), adaptive **weak-key drill**, punctuation/numbers/difficulty options, **ghost race** against your personal best. |
| **Storybook** | 6 books / 21 chapters (Aesop, Carroll, Doyle, Austen + originals). Finish a chapter to unlock the next, page-turn transition, per-chapter stats, bookshelf of completed covers. |
| **Lessons** | 26 lessons: home row → top → bottom → numbers → capitals/punctuation → symbols → sentences. On-screen keyboard with per-finger colours, highlighted next key + Shift, hands illustration, **no-peeking mode**, pass at 90% accuracy, 1–3 stars. |
| **Daily challenge** | Same for everyone each local day: Speed Sprint, Accuracy Hunt, Endurance, Weak-Key Drill, Themed. 3-2-1 countdown, month calendar, streak freezes shown. |
| **Retention** | Streak with a growing flame + milestones, streak freezes (earn every 7 days or buy with XP), daily-goal ring, XP + levels with a full-screen level-up, 31 badges, personal-best confetti + chime. |
| **Results** | Count-up numbers, WPM graph, most-missed keys, XP breakdown, streak, badges, and a shareable "Wrapped" card (save / copy image / copy text). |
| **Stats** | WPM & accuracy trends, records by mode, keyboard heatmap (mistakes / speed), totals, history, badge grid. |
| **Settings** | 6 themes (Dark, Light, Paper, Retro, Ocean, Neon — the last four unlock by level), text size, reduced-motion override, sound with volume, daily goal, export / import / reset. |
| **Quality** | WCAG AA contrast checked by test on every theme, full keyboard operation, reduced-motion support, corrupt-storage recovery, mid-session leave protection, pause on tab switch. |

## Decisions worth knowing

- **Persistence is local-only.** Clearing site data clears progress — use *Settings → Export progress* for a backup. Cloud sync / accounts (spec Phase 3) would need a backend (e.g. Supabase) and were deliberately not faked.
- **"Faster than X% of typists"** is measured against a model of typical typing speeds (mean ≈ 40 WPM), not live player data, and is labelled that way. There is no leaderboard for the same reason.
- **Typing is position-locked**: a wrong key is marked and the caret advances; Backspace fixes it. An extra stray key therefore shifts the rest of the line until corrected.
- **Content**: story text is public domain (retold/excerpted from memory with ASCII punctuation) or original. Give the classic excerpts a proofread before a public launch.
- **Not built** (spec "future / stretch"): multiplayer races, global leaderboards, EPUB import, other keyboard layouts.

## Adding stories

Drop a new file into `src/data/library/` (copy any existing one) and it appears in the Storybook automatically.
Set `category`, `added: 'YYYY-MM-DD'` (newest stories are listed first) and write chapters with plain keyboard characters only.
Chapters in the Cricket, Adventure and Growth categories must be at least 1,000 words; `npm test` enforces this.

## Project layout

```
src/
  lib/        engine, progress (XP/streak), text generation, challenges, badges, audio, fingers
  data/       words, quotes, stories, lessons, code snippets  (add content here — no code changes)
  store/      persisted zustand store; completeSession() is the single source of truth for rewards
  components/ TypingSession, TypingText (caret), KeyboardVisual, ResultsView, ShareCard, charts…
  pages/      Home, Practice, Storybook, Lessons, Challenge, Stats, Settings, Welcome
```
